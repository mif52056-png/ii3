# JARVIS Desktop — настольный ассистент

JARVIS Desktop — локальное приложение для Windows/macOS/Linux на Electron. В проекте есть рабочее окно приложения, панель состояния компьютера, чат, голосовой ввод (если доступен движок Web Speech в сборке), озвучивание ответов, локальные заметки и задачи, запуск ограниченного набора системных приложений и подключение OpenAI-совместимого API.

## Что работает сразу, без API-ключа

- Запуск калькулятора, блокнота, проводника/домашней папки и диспетчера задач/монитора системы.
- Открытие YouTube, Google, Wikipedia и GitHub.
- Поиск Google по команде `найди ...`.
- Время и дата.
- Заметки: `запомни купить молоко`, `покажи заметки`.
- Задачи: `добавь задачу закончить проект`, `покажи задачи`.
- Панель с ОС, моделью CPU, числом ядер и использованием оперативной памяти.
- История сообщений, заметки и задачи сохраняются в профиле приложения на этом компьютере.

## Установка и запуск на Windows

1. Установи Node.js 22 или 24 (желательно LTS) с официального сайта: https://nodejs.org/
2. Распакуй папку `jarvis-desktop`.
3. Запусти `УСТАНОВИТЬ_И_ЗАПУСТИТЬ.bat`.
4. При первом запуске скрипт установит зависимости, затем откроет приложение.

Либо открой терминал в папке проекта и выполни:

```bash
npm install
npm start
```

## Создание установщика EXE

На Windows запусти `СОБРАТЬ_EXE.bat` или выполни:

```bash
npm install
npm run dist:win
```

Готовый установщик появится в папке `dist` с именем вида `JARVIS-Setup-1.0.0.exe`. Сборку Windows рекомендуется выполнять именно на Windows-машине.

## Подключение ИИ

Открой в приложении **Настройки → Подключение модели**. Укажи:

- API Base URL — базовый адрес провайдера с совместимым endpoint Chat Completions, например `https://api.openai.com/v1`.
- Модель, доступную твоему провайдеру.
- API-ключ.

Приложение само добавит `/chat/completions`, если он не указан. Поддерживаются HTTPS-адреса; HTTP разрешён только для `localhost` и `127.0.0.1` (локальные модели). Ключ шифруется средствами ОС через Electron `safeStorage` и не передаётся в интерфейс после сохранения.

Без API-ключа свободный диалог с языковой моделью недоступен, но все встроенные команды продолжают работать.

## Данные и безопасность

- Все данные приложения находятся в системной папке профиля Electron (`userData`), а не в исходниках проекта.
- API-ключ хранится отдельно от обычных настроек и шифруется через `safeStorage`.
- У renderer-процесса отключён Node.js integration; включены `contextIsolation` и sandbox; доступ к функциям main-процесса дан только через узкий preload API.
- JARVIS запускает только перечисленные в коде программы. Он не принимает произвольные команды PowerShell, CMD или shell.
- При использовании внешнего API текст чата отправляется указанному провайдеру. Условия хранения данных определяет этот провайдер.

## Границы текущей версии

Это функциональная настольная основа, а не автономный ИИ с полным контролем ПК. Ассистент не видит экран, не читает файлы самовольно, не управляет мышью/клавиатурой и не исполняет любые команды ОС. Голосовое распознавание зависит от поддержки Web Speech в используемой версии Chromium и может требовать интернет-соединение; озвучивание использует голоса системы.
